Conceptos fundamentales

Base de datos

Es un conjunto organizado de información que puede almacenarse, consultarse y modificarse.

Tabla

Es donde se almacena la información organizada mediante filas y columnas.

Clave primaria

Identifica de manera única cada registro de una tabla.

Clave foránea

Permite relacionar una tabla con otra mediante un campo que referencia una clave primaria.
