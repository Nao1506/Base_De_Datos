Consultas SQL

SELECT

Se utiliza para consultar información de una tabla. 

SELECT nombre, edad
FROM alumnos;

WHERE

Permite establecer una condición para seleccionar determinados registros. 

SELECT *
FROM alumnos
WHERE edad > 18;

ORDER BY

Permite ordenar los resultados. 

SELECT nombre, nota
FROM alumnos
ORDER BY nota DESC;
Dato: SQL permite trabajar con grandes cantidades de información de manera organizada.
