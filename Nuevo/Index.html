Sistemas de Bases de Datos Relacionales

¿Qué es MySQL?

Es un sistema de gestión de bases de datos relacional (RDBMS) basado en el lenguaje estructurado de consultas (SQL). Es rápido, seguro, de código abierto y fundamental para el desarrollo web moderno.

Introducción

¿Cómo funciona?

MySQL almacena la información en tablas compuestas por filas y columnas. Cada fila representa un registro único y cada columna un campo con un tipo de dato específico.

Utiliza una arquitectura cliente-servidor, donde las aplicaciones solicitan datos al servidor de MySQL mediante sentencias SQL, y este procesa y devuelve los resultados.

Se destaca por ser una herramienta eficiente, escalable, confiable y con un soporte masivo en la comunidad del desarrollo de software.

Comandos Principales

Las sentencias básicas del lenguaje estructurado de consultas (SQL):

🔍

SELECT

Se utiliza para consultar y traer datos específicos desde una o más tablas de la base de datos.

➕

INSERT

Permite agregar nuevas filas o registros de datos dentro de una tabla existente.

🔄

UPDATE

Se usa para modificar o actualizar los valores de los registros que ya están guardados.

Tipos de Datos

Formatos más utilizados

Al definir columnas, debemos elegir el tipo de dato correcto:

  • 🔢 INT - Números enteros
  • 🔤 VARCHAR - Cadenas de texto variables
  • 📅 DATE - Formato de fecha (AAAA-MM-DD)
  • 🪙 DECIMAL - Números con punto flotante exactos

"Clave Primaria (Primary Key)"

- "Identifica cada registro de forma única."

"Clave Foránea (Foreign Key)"

- "Vincula y relaciona las tablas entre sí."

Normalización

Seguridad
