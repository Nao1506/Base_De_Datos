¿Qué es un DER?

El Diagrama Entidad-Relación es una representación gráfica que permite diseñar la estructura de una base de datos. Muestra las entidades, sus atributos y las relaciones que existen entre ellas.

📦 Entidad

Representa un objeto o concepto del mundo real, como un alumno, un curso o un producto.

📝 Atributo

Es una característica de una entidad, como el nombre, la edad o el identificador.

🔗 Relación

Representa la asociación entre dos o más entidades.

Ejemplo: Alumnos y cursos

Un curso puede tener muchos alumnos, pero cada alumno pertenece a un solo curso.

Tipos de relaciones

1 : 1

Uno a uno

Una entidad se relaciona con una sola entidad de la otra tabla.

Ejemplo: Persona - DNI

1 : N

Uno a muchos

Una entidad puede relacionarse con muchas entidades de la otra tabla.

Ejemplo: Curso - Alumnos

N : M

Muchos a muchos

Muchas entidades de una tabla pueden relacionarse con muchas de otra.

Ejemplo: Alumnos - Materias

Del DER a MySQL

Una vez diseñado el diagrama, podemos crear las tablas correspondientes utilizando SQL. 

CREATE TABLE cursos (
    id_curso INT PRIMARY KEY,
    nombre_curso VARCHAR(50),
    turno VARCHAR(20)
);

CREATE TABLE alumnos (
    id_alumno INT PRIMARY KEY,
    nombre VARCHAR(50),
    edad INT,
    id_curso INT,
    FOREIGN KEY (id_curso)
        REFERENCES cursos(id_curso)
);
Importante: La clave foránea id_curso de la tabla alumnos referencia la clave primaria id_curso de cursos. Esto permite relacionar ambas tablas.
